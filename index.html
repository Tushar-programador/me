Chapter 03

The Builds

Project 01
Production
Relook
A multi-tenant SaaS platform where businesses collect, moderate, and publish customer testimonials in video, audio, and text formats. Each business account has fully isolated data with its own branding config. OTP-based authentication handles both business owners and their customers. Media uploads go through a Cloudinary pipeline that validates format, enforces size limits, and generates thumbnails. Admins get a moderation queue to approve or reject submissions before they go live. An embeddable widget API generates a snippet any site can drop in to display live testimonials — no frontend rebuild needed. Usage analytics (submissions, views, conversion) are tracked per account.
React Node.js Express MongoDB Cloudinary OTP Auth Multi-tenant
SaaS Platform ↗
Project 02
In Development
Outdraw
A cloud application platform where developers deploy apps that run entirely in the cloud with centrally governed user data — similar in spirit to Replit or Railway but built around data ownership. The Go service handles app registration, Docker container lifecycle (spawn, health-check, teardown), and request routing to the right container per user session. The Node.js control plane manages authentication, user-to-app binding, and multi-tenant session isolation so users never cross data boundaries. The goal: developers push code, users get a running app — no infra knowledge required.
Go Node.js Docker Multi-tenant REST APIs JWT Auth
Cloud Platform ↗
Project 03
Production
ICMS — Inventory & Chain Management
An enterprise backend system built at Vervebot.io and running in production. Manages inventory, supply chain, and invoicing for a real business. Barcode scanners hit the REST API directly — product data lands in MongoDB without a human typing it, cutting manual entry by 60%. Invoice generation is automated end-to-end: line items are resolved from inventory, tax is calculated, a PDF is produced and stored, and the record is reconciled — reducing processing time by 50%. A WebSocket layer keeps warehouse and office dashboards in sync in real time. MongoDB aggregation pipelines back the analytics module management uses for restocking and sales decisions every day.
Node.js Express MongoDB React WebSockets REST APIs
